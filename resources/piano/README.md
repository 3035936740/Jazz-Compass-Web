- These MP3 files (one every minor third, A0–C8) are the copies hosted by Tone.js:
  https://tonejs.github.io/audio/salamander/

The files are unmodified. At runtime `script.js` trims the leading silence, keeps 4–7 seconds
of each note and retunes it with `playbackRate` to the requested pitch.
